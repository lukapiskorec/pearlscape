# Pearlscape — Rhino Python

See the project root [`README.md`](../README.md) for full documentation: parameters, modes, architecture, and known gotchas.

## Quick start

1. Open Rhino 8 with document units set to **millimetres**.
2. Run `_ScriptEditor` (the new editor, not the legacy `_EditPythonScript`).
3. Open `build_scene.py`, press **F5**.

Edit `pearlscape/params.py` to tune parameters; the script picks up changes automatically on each F5.
